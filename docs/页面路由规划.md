## 二、路由结构设计

### 2.1 小程序原生页面与H5页面分工

```
┌─────────────────────────────────────────────────────────────┐
│                    微信小程序容器                             │
├─────────────────────────────────────────────────────────────┤
│  原生层（pages/）                                            │
│  ├── 负责：小程序生命周期、TabBar、登录态检查、club_id注入      │
│  ├── pages/index/index          - 首页壳+WebView容器           │
│  └── pages/webview/container   - WebView页面加载器            │
│                                                              │
│  H5层（WebView内嵌）                                         │
│  ├── 负责：业务逻辑、页面渲染、用户交互                         │
│  ├── 通过 postMessage 与小程序原生通信                         │
│  └── 通过 URL 参数接收 club_id                               │
└─────────────────────────────────────────────────────────────┘
```

**分工原则**：
- **小程序原生层**：只负责基础设施（生命周期、路由、TabBar、登录检查、club_id传递）
- **H5页面**：承载所有业务逻辑，通过 WebView 加载，实现"一次开发，多端复用"

### 2.2 club_id 参数传递机制

```
┌──────────────────────────────────────────────────────────────┐
│                    club_id 传递流程                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  场景1：带参数二维码扫码进入                                    │
│  ┌─────────┐     ┌─────────────┐     ┌─────────────────┐   │
│  │ 微信扫描 │ ──→ │ 小程序启动  │ ──→ │ 获取 club_id    │   │
│  │  二维码  │     │ onLoad      │     │ from query      │   │
│  └─────────┘     └─────────────┘     └────────┬────────┘   │
│                                               │              │
│                                               ▼              │
│  ┌─────────────────────────────────────────────────────────┐│
│  │         存储到 Storage + 全局变量                        ││
│  │         wx.setStorageSync('club_id', club_id)          ││
│  └─────────────────────────────────────────────────────────┘│
│                                               │              │
│                                               ▼              │
│  ┌─────────────────────────────────────────────────────────┐│
│  │         注入到 WebView H5                               ││
│  │         URL: https://xxx.com/h5/activities?club_id=xxx ││
│  └─────────────────────────────────────────────────────────┘│
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  场景2：内部页面跳转                                          │
│  ┌─────────────┐     ┌──────────────────────────────────┐   │
│  │  H5 发起跳转 │ ──→ │ 通过 URL 参数传递 club_id         │   │
│  └─────────────┘     │ /h5/activity/123?club_id=xxx     │   │
│                      └──────────────────────────────────┘   │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  场景3：club_id 为空（共享版入口）                             │
│  ┌─────────────┐     ┌──────────────────────────────────┐   │
│  │ club_id     │ ──→ │ 跳转到俱乐部选择页                │   │
│  │    空       │     │ /h5/clubs                        │   │
│  └─────────────┘     └──────────────────────────────────┘   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 四、页面详情说明

### 4.1 MVP阶段页面

#### 4.1.1 首页（原生壳）

```
┌─────────────────────────────────────┐
│  小程序原生头部                      │
│  - 状态栏沉浸                       │
│  - 俱乐部Logo（个性化）             │
│  - 俱乐部名称（个性化）              │
├─────────────────────────────────────┤
│                                     │
│           WebView 容器              │
│                                     │
│   嵌入 H5 页面（默认活动列表）        │
│                                     │
│                                     │
│                                     │
│                                     │

│  TabBar（原生）                      │
│  [首页] [活动] [知识] [我的]          │
└─────────────────────────────────────┘
```

**核心逻辑**：
- 小程序启动时从 Storage 读取 club_id
- club_id 为空时，WebView 加载俱乐部选择页
- club_id 存在时，WebView 加载对应俱乐部的 H5 页面
- TabBar 切换通过小程序 API 操作 WebView 的 URL

## 七、关键技术说明

### 7.1 小程序与H5通信机制

```javascript
// 小程序端 - 发送消息到H5
wx.miniProgram.postMessage({
  data: {
    type: 'club_config',
    club_id: 'CLUB_001',
    theme: { primary_color: '#2E7D32' }
  }
});

// H5端 - 接收消息
window.addEventListener('message', function(e) {
  if (e.data.type === 'club_config') {
    // 更新主题配置
    document.documentElement.style.setProperty(
      '--primary-color', 
      e.data.theme.primary_color
    );
  }
});
```

### 7.2 H5路由守卫

```javascript
// 路由守卫示例
router.beforeEach((to, from, next) => {
  const club_id = localStorage.getItem('club_id');
  const token = localStorage.getItem('token');
  
  // 无club_id，跳转到俱乐部选择页
  if (!club_id && to.path !== '/clubs') {
    return next('/clubs');
  }
  
  // 需要登录的页面
  if (to.meta.requiresAuth && !token) {
    // 跳转微信授权页
    return next('/auth/login');
  }
  
  next();
});
```

### 7.3 club_id注入到H5 URL

```javascript
// 小程序端
const club_id = wx.getStorageSync('club_id');
const h5Url = `https://xxx.com/h5/activities?club_id=${club_id}`;

// 加载到WebView
this.setData({
  webviewSrc: h5Url
});
```
