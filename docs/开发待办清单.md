## 一、已有代码问题修复（优先级最高）

### 1.1 编译/运行错误
- [ ] **TenantInterceptor 用了 javax.servlet**：SpringBoot 3 必须用 `jakarta.servlet`，否则编译不过
- [ ] **MyBatis-Plus 与若依原生 MyBatis 冲突**：若依用的是原生MyBatis（非Plus），直接加MybatisPlus会导致两套框架并存，需要确认是否做了兼容处理，或者统一迁移到MyBatis-Plus
- [ ] **ruoyi-outdoor 模块是否注册到父 pom**：新增的模块需要在根 `pom.xml` 的 `<modules>` 中声明

### 1.2 与Spec不一致
- [ ] **Club domain JSONB字段**：当前用 `String` 存储，应改为实体类 + Jackson TypeHandler，或至少在 Mapper XML 中做 JSONB 映射
- [ ] **ActivityController 路径**：当前 `/outdoor/activity`，用户端应为 `/api/activities`，管理端应为 `/admin/activity`
- [ ] **H5 路由路径**：当前 `/home`、`/activity/:id`，应改为 `/h5/activities`、`/h5/activity/:id`（Spec定义）
- [ ] **Club domain 字段缺失**：缺少 `club_id`（多租户隔离字段）、`latitude/longitude`、`wx_app_id/wx_app_secret`、`package_type/expire_time` 等Spec中定义的字段
