#### 2.3.3 分页插件配置

```java
// PostgreSQL分页配置
@Configuration
public class MybatisPlusConfig {
    
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        
        // PostgreSQL方言分页
        interceptor.addInnerInterceptor(new PostgreSQLInnerInterceptor());
        
        // 多租户插件（club_id自动注入）
        interceptor.addInnerInterceptor(new TenantLineInnerInterceptor(
            new TenantLineHandler() {
                @Override
                public Expression getTenantId() {
                    // 从ThreadLocal获取当前club_id
                    return new LongValue(TenantContextHolder.getTenantId());
                }
                
                @Override
                public String getTenantIdColumn() {
                    return "club_id";
                }
                
                @Override
                public boolean ignoreTable(String tableName) {
                    // 忽略系统表（不需要club_id过滤）
                    return Arrays.asList(
                        "sys_user", "sys_role", "sys_menu", 
                        "sys_dict_type", "sys_dict_data",
                        "sys_config", "sys_notice"
                    ).contains(tableName);
                }
            }
        ));
        
        return interceptor;
    }
}
```

#### 2.3.4 SQL方言差异处理

| 差异点 | MySQL写法 | PostgreSQL写法 |
|-------|----------|---------------|
| 主键自增 | `id BIGINT PRIMARY KEY AUTO_INCREMENT` | `id BIGINT GENERATED ALWAYS AS IDENTITY` |
| 批量插入 | `INSERT INTO ... VALUES (1),(2)` | 相同 |
| 日期函数 | `NOW()` | `NOW()` 或 `CURRENT_TIMESTAMP` |
| 字符串截取 | `SUBSTRING(col, 1, 10)` | `SUBSTRING(col FROM 1 FOR 10)` |
| JSON字段查询 | `JSON_EXTRACT` | `->` 或 `#> ` |
| JSONB包含 | `JSON_CONTAINS` | `@>` |
| 分页偏移 | `LIMIT 10 OFFSET 20` | `LIMIT 10 OFFSET 20` |
| 布尔类型 | `TINYINT(1)` | `BOOLEAN` |
| 文本类型 | `VARCHAR(255)` | `VARCHAR(255)` |
| 大文本 | `TEXT` | `TEXT`（无长度限制） |

#### 2.3.5 数据类型映射

| Java类型 | MySQL类型 | PostgreSQL类型 |
|---------|----------|---------------|
| Long | BIGINT | BIGINT |
| Integer | INT | INTEGER |
| BigDecimal | DECIMAL(10,2) | DECIMAL(10,2) |
| String | VARCHAR | VARCHAR |
| String (长文本) | TEXT | TEXT |
| Boolean | TINYINT(1) | BOOLEAN |
| LocalDateTime | DATETIME | TIMESTAMP |
| Date | DATE | DATE |
| List/Map | JSON | JSONB |
| byte[] | VARBINARY | BYTEA |

#### 3.2.2 核心实现

**1. TenantContextHolder - 租户上下文持有者**

```java
public class TenantContextHolder {
    
    private static final ThreadLocal<Long> TENANT_ID = new ThreadLocal<>();
    
    public static void setTenantId(Long clubId) {
        TENANT_ID.set(clubId);
    }
    
    public static Long getTenantId() {
        return TENANT_ID.get();
    }
    
    public static void clear() {
        TENANT_ID.remove();
    }
}
```

**2. TenantInterceptor - 租户拦截器**

```java
@Component
public class TenantInterceptor extends HandlerInterceptorAdapter {
    
    @Override
    public boolean preHandle(HttpServletRequest request, 
                            HttpServletResponse response, 
                            Object handler) {
        
        // 1. 从请求头获取club_id（前端传入）
        String clubIdHeader = request.getHeader("X-Club-Id");
        
        // 2. 如果没有，从Token解析
        if (StringUtils.isBlank(clubIdHeader)) {
            String token = request.getHeader("Authorization");
            if (StringUtils.isNotBlank(token)) {
                clubIdHeader = extractClubIdFromToken(token);
            }
        }
        
        // 3. 设置到ThreadLocal
        if (StringUtils.isNotBlank(clubIdHeader)) {
            TenantContextHolder.setTenantId(Long.parseLong(clubIdHeader));
        }
        
        return true;
    }
    
    @Override
    public void afterCompletion(HttpServletRequest request, 
                               HttpServletResponse response, 
                               Object handler, Exception ex) {
        TenantContextHolder.clear();
    }
}
```

**3. MyBatis TenantLineHandler**

```java
public class CustomTenantHandler implements TenantLineHandler {
    
    @Override
    public Expression getTenantId() {
        Long clubId = TenantContextHolder.getTenantId();
        if (clubId == null) {
            throw new BizException("Club ID is required");
        }
        return new LongValue(clubId);
    }
    
    @Override
    public String getTenantIdColumn() {
        return "club_id";
    }
    
    @Override
    public boolean ignoreTable(String tableName) {
        // 系统表不进行租户过滤
        return IGNORE_TABLES.contains(tableName);
    }
    
    private static final Set<String> IGNORE_TABLES = new HashSet<>(Arrays.asList(
        "sys_user", "sys_role", "sys_menu", "sys_dept",
        "sys_dict_type", "sys_dict_data", "sys_config",
        "sys_notice", "sys_post", " sys_login_log"
    ));
}
```

#### 3.2.3 使用示例

```java
// 业务代码中无需手动添加 club_id 条件
@Service
public class ActivityServiceImpl implements IActivityService {
    
    @Autowired
    private IActivityMapper activityMapper;
    
    // 无论多少俱乐部调用，club_id 自动注入
    public List<ActivityEntity> getActivityList(ActivityQueryDTO query) {
        // MyBatis-Plus 自动拼接 WHERE club_id = ?
        LambdaQueryWrapper<ActivityEntity> wrapper = 
            new LambdaQueryWrapper<ActivityEntity>()
                .eq(ActivityEntity::getStatus, "recruiting")
                .orderByDesc(ActivityEntity::getStartTime);
        
        return activityMapper.selectList(wrapper);
    }
}
```

**生成的SQL自动包含club_id**：
```sql
SELECT * FROM act_activity 
WHERE club_id = 1 
  AND status = 'recruiting' 
ORDER BY start_time DESC
```

```javascript
class ClubJSBridge {
  
  // 获取俱乐部ID
  getClubId() {
    return new Promise((resolve, reject) => {
      wx.miniProgram.getEnv((res) => {
        if (res.miniprogram) {
          wx.miniProgram.postMessage({ type: 'getClubId' });
          // 监听小程序返回

            if (event.data.type === 'clubIdResponse') {
              resolve(event.data.clubId);
            }
          });
        } else {
          // H5独立运行模式
          const urlParams = new URLSearchParams(window.location.search);
          resolve(urlParams.get('club_id'));
        }
      });
    });
  }
  
  // 获取用户Token
  getUserToken() {
    return new Promise((resolve, reject) => {
      wx.miniProgram.getEnv((res) => {
        if (res.miniprogram) {
          wx.miniProgram.postMessage({ type: 'getUserToken' });
          window.addEventListener('message', (event) => {
            if (event.data.type === 'tokenResponse') {
              resolve(event.data.token);
            }
          });
        } else {
          resolve(localStorage.getItem('token'));
        }
      });
    });
  }
  
  // 跳转页面
  navigateTo(path: string, params?: Record<string, string>) {
    const query = params ? '?' + new URLSearchParams(params).toString() : '';
    wx.miniProgram.navigateTo({ 
      url: `/pages/webview/container?url=${encodeURIComponent(path + query)}` 
    });
  }
  
  // 跳转TabBar页面
  switchTab(path: string) {
    wx.miniProgram.switchTab({ url: path });
  }
  
  // 分享
  showShareMenu(options: { title: string; path: string; imageUrl?: string }) {
    wx.miniProgram.postMessage({ 
      type: 'showShareMenu', 
      ...options 
    });
  }
  
  // 调起微信支付
  requestPayment(params: WxPayParams) {
    return new Promise((resolve, reject) => {
      wx.miniProgram.postMessage({ type: 'requestPayment', ...params });
      window.addEventListener('message', (event) => {
        if (event.data.type === 'paymentResult') {
          if (event.data.success) {
            resolve(event.data);
          } else {
            reject(new Error(event.data.message));
          }
        }
      });
    });
  }
}
```

```java
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, 
                                    HttpServletResponse response, 
                                    FilterChain chain) throws ServletException, IOException {
        
        String token = request.getHeader("Authorization");
        
        if (StringUtils.isNotBlank(token) && token.startsWith("Bearer ")) {
            token = token.substring(7);
            
            try {
                // 验证Token
                Claims claims = JwtUtils.parseToken(token);
                String userId = claims.getSubject();
                Long clubId = claims.get("clubId", Long.class);
                
                // 设置用户上下文
                UserContext.setUserId(userId);
                TenantContextHolder.setTenantId(clubId);
                
                // 设置认证信息
                UsernamePasswordAuthenticationToken authentication = 
                    new UsernamePasswordAuthenticationToken(userId, null, new ArrayList<>());
                SecurityContextHolder.getContext().setAuthentication(authentication);
                
            } catch (JwtException e) {
                // Token无效，返回401
                response.setStatus(401);
                response.getWriter().write("{\"code\":401,\"msg\":\"Token已过期\"}");
                return;
            }
        }
        
        chain.doFilter(request, response);
    }
}
```

```java
        "UNION", "SELECT", "INSERT", "UPDATE", "DELETE",

        if ("POST".equalsIgnoreCase(request.getMethod())) {

// 自定义请求包装器
public class XssRequestWrapper extends HttpServletRequestWrapper {
    
    public XssRequestWrapper(HttpServletRequest request) {
        super(request);
    }
    
    @Override
    public String[] getParameterValues(String name) {
        String[] values = super.getParameterValues(name);
        if (values == null) return null;
        
        return Arrays.stream(values)
            .map(this::escapeSql)
            .map(this::escapeHtml)
            .toArray(String[]::new);
    }
    
    private String escapeSql(String value) {
        if (value == null) return null;
        return value.replaceAll("([';]+|(--)+)", "");
    }
    
    private String escapeHtml(String value) {
        if (value == null) return null;
        return value.replaceAll("<", "&lt;")
                    .replaceAll(">", "&gt;")
                    .replaceAll("\"", "&quot;");
    }
}
```

```java
// 响应结果封装
@Data
public class AjaxResult {
    
    private int code;       // 状态码

    private Object data;    // 数据
    
    // 成功响应

    }
    
    public static AjaxResult success(Object data) {
        return success("操作成功", data);
    }
    
    public static AjaxResult success(String msg, Object data) {
        AjaxResult result = new AjaxResult();
        result.setCode(200);
        result.setMsg(msg);
        result.setData(data);
        return result;
    }
    
    // 失败响应

        return error("操作失败", 500);
    }
    
    public static AjaxResult error(String msg) {
        return error(msg, 500);
    }
    
    public static AjaxResult error(String msg, int code) {
        AjaxResult result = new AjaxResult();
        result.setCode(code);
        result.setMsg(msg);
        return result;
    }
}

// 分页响应
@Data
public class PageResult<T> {
    private long total;         // 总记录数
    private long pageNum;       // 当前页码
    private long pageSize;      // 每页数量
    private List<T> rows;       // 数据列表

        result.setTotal(page.getTotal());
        result.setPageNum(page.getCurrent());
        result.setPageSize(page.getSize());
        result.setRows(page.getRecords());
        return result;
    }
}
```

### 6.2 WebView 容器规范

```typescript
// pages/webview/container.js
Page({
  data: {
    webviewSrc: '',
    clubId: '',
    clubName: '',
    clubLogo: ''
  },
  
  onLoad(options) {
    // 1. 获取club_id
    const clubId = options.club_id || '';
    const webUrl = decodeURIComponent(options.url || '/h5/activities');
    
    // 2. 存储club_id
    wx.setStorageSync('club_id', clubId);
    
    // 3. 拼接完整URL
    const fullUrl = webUrl.includes('?') 
      ? `${webUrl}&club_id=${clubId}`
      : `${webUrl}?club_id=${clubId}`;
    
    this.setData({ 
      webviewSrc: fullUrl,
      clubId
    });
  },
  
  // 监听WebView消息
  onWebViewMessage(e) {
    const { type, ...params } = e.detail.data[0];
    
    switch (type) {
      case 'getClubInfo':
        this.sendToWebView({
          type: 'clubInfo',
          clubId: this.data.clubId,
          clubName: this.data.clubName,
          clubLogo: this.data.clubLogo
        });
        break;
        
      case 'navigate':
        this.handleNavigate(params);
        break;
        
      case 'payment':
        this.handlePayment(params);
        break;
        
      case 'subscribeMessage':
        this.handleSubscribe(params);
        break;
    }
  },
  
  // 发送消息到H5
  sendToWebView(data) {
    this.setData({ webviewMessage: data });
  },
  
  // 处理页面跳转
  handleNavigate(params) {
    const { path, params: queryParams } = params;
    const query = queryParams ? '?' + Object.entries(queryParams)
      .map(([k, v]) => `${k}=${v}`).join('&') : '';
    
    // 如果是TabBar页面
    if (params.isTab) {
      wx.switchTab({ url: path + query });
    } else {
      wx.navigateTo({ url: `/pages/webview/container?url=${encodeURIComponent(path + query)}` });
    }
  }
});
```

```java
@RestController
@RequestMapping("/api/auth")
public class AuthController {
    
    @Autowired
    private WxMaService wxMaService;
    
    @Autowired
    private IWxUserService wxUserService;
    
    @Autowired
    private TokenService tokenService;
    
    /**
     * 微信登录
     */
    @PostMapping("/login")
    public AjaxResult login(@RequestBody LoginDTO dto) {
        // 1. 小程序登录获取 code
        String code = dto.getCode();
        
        // 2. 调用微信接口获取 openid
        WxMaJscode2SessionResult sessionResult;
        try {
            sessionResult = wxMaService.getUserService()
                .getSessionInfo(code);
        } catch (WxErrorException e) {
            log.error("微信登录失败", e);
            return AjaxResult.error("微信登录失败");
        }
        
        String openid = sessionResult.getOpenid();
        String sessionKey = sessionResult.getSessionKey();
        
        // 3. 获取 club_id（从请求头或上下文）
        Long clubId = getClubId();
        
        // 4. 查询或创建用户
        WxUserEntity user = wxUserService.getOrCreateUser(clubId, openid, sessionKey);
        
        // 5. 更新登录信息
        wxUserService.updateLoginInfo(user.getUserId());
        
        // 6. 生成 Token
        String token = tokenService.generateToken(user.getUserId(), clubId);
        
        // 7. 返回结果
        Map<String, Object> result = new HashMap<>();
        result.put("token", token);
        result.put("userInfo", convertUserInfo(user));
        
        return AjaxResult.success(result);
    }
    
    /**
     * 绑定手机号（可选流程）
     */
```

```java
@RequestMapping("/api/pay")
public class PaymentController {

    private IOrderService orderService;

        Long clubId = getClubId();
        
        // 2. 验证报名记录
        RegistrationEntity reg = registrationService.getById(dto.getRegId());
        if (reg == null) {
            return AjaxResult.error("报名记录不存在");
        }
        
        // 3. 创建订单
        OrderEntity order = orderService.createOrder(clubId, userId, reg);
        
        // 4. 调用微信支付统一下单
        WxPayUnifiedOrderRequest request = new WxPayUnifiedOrderRequest();
        request.setOutTradeNo(order.getOrderNo());
        request.setTotalFee((int) (order.getTotalAmount().multiply(new BigDecimal("100")).longValue()));
        request.setBody(order.getActivityTitle() + "-活动报名费");
        request.setTradeType("JSAPI");
        request.setOpenid(getOpenid());
        request.setNotifyUrl(wxPayProperties.getPayNotifyUrl());
        
        // 设置俱乐部子商户（分账模式）
        if (StringUtils.isNotBlank(club.getSubMchId())) {
            request.setSubMchId(club.getSubMchId());
        }
        
        // 5. 调用微信接口
        WxPayUnifiedOrderResult result = wxPayService.unifiedOrder(request);
        
        // 6. 构建前端支付参数
        Map<String, String> payParams = new HashMap<>();
        payParams.put("appId", result.getAppid());
        payParams.put("timeStamp", String.valueOf(System.currentTimeMillis() / 1000));
        payParams.put("nonceStr", result.getNonceStr());
        payParams.put("package", "prepay_id=" + result.getPrepayId());
        payParams.put("signType", "MD5");
        payParams.put("paySign", generatePaySign(payParams));
        
        // 7. 返回结果
        Map<String, Object> data = new HashMap<>();
        data.put("orderId", order.getOrderId());
        data.put("orderNo", order.getOrderNo());
        data.put("totalAmount", order.getTotalAmount());
        data.put("payParams", payParams);
        
        return AjaxResult.success(data);
    }
    
    /**
     * 支付回调
     */
    @PostMapping("/callback")
    public String payCallback(HttpServletRequest request, HttpServletResponse response) {
        try {
            // 1. 解析回调数据
            String xmlData = readRequestBody(request);
            WxPayOrderNotifyResult result = wxPayService.parseOrderNotifyResult(xmlData);
            
            // 2. 验证签名
            if (!result.checkSign(wxPayService.getConfig().getMchKey())) {
                log.error("支付回调签名验证失败");
                return "<xml><return_code>FAIL</return_code><return_msg>签名错误</return_msg></xml>";
            }
            
            // 3. 处理支付结果
            String orderNo = result.getOutTradeNo();
            OrderEntity order = orderService.getByOrderNo(orderNo);
            
            if (order != null && order.getPayStatus() == 0) {
                // 4. 更新订单状态
                orderService.updatePayStatus(order.getOrderId(), 
                    result.getTransactionId(), 
                    result.getTimeEnd());
                
                // 5. 更新报名状态
                registrationService.updateStatus(order.getRegId(), 3); // 已通过
                
                // 6. 发送模板消息
                messageService.sendPaySuccessNotice(order);
                
                // 7. 更新活动报名人数
                activityService.incrCurrentMembers(order.getActivityId());
            }
            
            return "<xml><return_code>SUCCESS</return_code><return_msg>OK</return_msg></xml>";
            
        } catch (Exception e) {

            return "<xml><return_code>FAIL</return_code><return_msg>处理异常</return_msg></xml>";
```

### 7.4 阿里云OSS文件上传

```java
// FileController.java
@RestController
@RequestMapping("/api/file")
public class FileController {
    
    @Autowired
    private OSSProperties ossProperties;
    
    /**
     * 上传文件
     */
    @PostMapping("/upload")
    public AjaxResult upload(@RequestParam("file") MultipartFile file) {
        // 1. 验证文件
        if (file.isEmpty()) {
            return AjaxResult.error("请选择文件");
        }
        
        // 2. 验证文件类型
        String originalFilename = file.getOriginalFilename();
        String ext = originalFilename.substring(originalFilename.lastIndexOf("."));
        if (!isAllowedExt(ext)) {
            return AjaxResult.error("不支持的文件类型");
        }
        
        // 3. 生成文件名
        String objectName = generateObjectName(ext);
        
        // 4. 上传到OSS
        try {
            OSSClient ossClient = new OSSClient(
                ossProperties.getEndpoint(),
                ossProperties.getAccessKeyId(),
                ossProperties.getAccessKeySecret()
            );
            
            ossClient.putObject(ossProperties.getBucketName(), objectName, file.getInputStream());
            
            // 5. 返回文件URL
            String url = ossProperties.getCdnDomain() + "/" + objectName;
            
            return AjaxResult.success(Map.of(
                "url", url,
                "filename", objectName
            ));
            
        } catch (Exception e) {
            log.error("文件上传失败", e);
            return AjaxResult.error("文件上传失败");
        }
    }
    
    private String generateObjectName(String ext) {
        return String.format("outdoor/%s/%s%s",
            DateUtils.datePath(), // 2025/03/15
            UUID.randomUUID().toString().replace("-", ""),
            ext
        );
    }
}
```
